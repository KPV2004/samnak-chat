# ติดตั้งบนเซิร์ฟเวอร์ของคุณ

หน้านี้อธิบายการรันทั้งระบบบนเครื่องเดียวด้วย Docker Compose ชุดบริการมีห้าตัว

- **web**: เว็บแอป ให้บริการโดย Caddy ซึ่งยังส่งต่อคำขอ API และจัดการ HTTPS ด้วย
- **server**: API และเซิร์ฟเวอร์ WebSocket
- **postgres**: ฐานข้อมูล (PostgreSQL 17)
- **redis**: ข้อมูลสถานะออนไลน์ และการกระจายข้อความแบบเรียลไทม์ระหว่างเซิร์ฟเวอร์
- **minio**: ที่เก็บไฟล์แนบ ใช้ API แบบ S3

บริการ `migrate` รันการย้ายโครงสร้างฐานข้อมูลหนึ่งครั้ง ก่อนที่เซิร์ฟเวอร์จะเริ่มทำงาน

## สิ่งที่ต้องมี

- Docker ที่มี Compose v2: Docker Desktop, OrbStack หรือ Docker Engine ที่ติดตั้งปลั๊กอิน Compose
- Git
- หน่วยความจำว่างประมาณ 2 GB และพื้นที่ดิสก์ประมาณ 5 GB สำหรับอิมเมจและข้อมูล

ไฟล์ Compose จะสร้างอิมเมจจากโค้ดที่คุณ clone มา การเริ่มครั้งแรกใช้เวลาหลายนาที ส่วนใหญ่เป็นการสร้างอิมเมจ

## ติดตั้ง

```sh
git clone https://github.com/KPV2004/samnak-chat.git
cd samnak-chat
cp .env.example .env
```

เปิดไฟล์ `.env` แล้วตั้งค่าต่อไปนี้ รายการตัวแปรทั้งหมดอยู่ในหน้า [การตั้งค่า](/th/configuration)

| การตั้งค่า | สิ่งที่ควรตั้ง |
| --- | --- |
| `JWT_SECRET` | สตริงสุ่มยาว ๆ เช่นผลลัพธ์ของ `openssl rand -hex 32` จำเป็นต้องตั้ง |
| `S3_ACCESS_KEY`, `S3_SECRET_KEY` | ค่าสุ่ม |
| `MINIO_ROOT_USER`, `MINIO_ROOT_PASSWORD` | ค่าเดียวกับ `S3_ACCESS_KEY` และ `S3_SECRET_KEY` |
| `PUBLIC_URL` | ที่อยู่ที่ผู้ใช้เปิด พร้อมพอร์ตถ้าไม่ใช่ 80 หรือ 443 เช่น `http://localhost` หรือ `https://chat.example.com` ลิงก์ในอีเมลและการอัปโหลดไฟล์ของเบราว์เซอร์ใช้ที่อยู่นี้ |
| `POSTGRES_PASSWORD` | ค่าสุ่ม ตั้งก่อนเริ่มครั้งแรก เพราะฐานข้อมูลจะจำรหัสผ่านที่ถูกสร้างไว้ตอนนั้น |
| `DOMAIN` | ชื่อโฮสต์ เช่น `chat.example.com` สำหรับ HTTPS อัตโนมัติ ถ้าใช้ HTTP ธรรมดาให้เว้นว่างไว้ |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM` | เซิร์ฟเวอร์อีเมลของคุณ ถ้าเว้น `SMTP_HOST` ไว้ ระบบจะเขียนอีเมลลงบันทึกของเซิร์ฟเวอร์แทน |

จากนั้นเริ่มระบบจากโฟลเดอร์รากของโครงการ

```sh
docker compose --env-file .env -f deploy/compose.prod.yml up -d --wait
```

`--wait` จะกลับมาเมื่อทุกบริการรายงานว่าสุขภาพดี เปิด `http://localhost` (หรือ `PUBLIC_URL` ของคุณ) สมัครบัญชี แล้วสร้างเวิร์กสเปซ บัญชีที่สร้างเวิร์กสเปซจะเป็น **เจ้าของ** ของเวิร์กสเปซนั้น

## HTTPS

ตั้ง `DOMAIN` เป็นชื่อโฮสต์ เช่น `chat.example.com` และตั้ง `PUBLIC_URL=https://chat.example.com` จากนั้น

- พอร์ต 80 และ 443 บนเครื่องนี้ต้องเข้าถึงได้จากอินเทอร์เน็ต เพราะใบรับรองถูกออกผ่าน HTTP
- ชื่อโฮสต์ต้องชี้มาที่เครื่องนี้อยู่แล้ว

Caddy จะขอใบรับรองและต่ออายุให้เอง ข้อมูลใบรับรองเก็บอยู่ในโวลุ่ม `caddydata`

## พอร์ต {#ports}

Caddy เปิดพอร์ต 80 และ 443 ถ้าต้องการใช้พอร์ตอื่นบนเครื่องโฮสต์ ให้ตั้งค่าในเชลล์ก่อนรันคำสั่ง และตั้ง `PUBLIC_URL` ให้มีพอร์ตเดียวกัน เพราะลิงก์ไฟล์ถูกลงนามไว้สำหรับที่อยู่นั้น

```sh
HTTP_PORT=8080 HTTPS_PORT=8443 PUBLIC_URL=http://localhost:8080 docker compose --env-file .env -f deploy/compose.prod.yml up -d --wait
```

มีเพียง Caddy เท่านั้นที่เปิดพอร์ตให้เข้าถึงจากภายนอก PostgreSQL, Redis, MinIO และเซิร์ฟเวอร์ เข้าถึงได้เฉพาะภายในเครือข่ายส่วนตัวของระบบ

## ลองบนคอมพิวเตอร์ของคุณ

วิธีนี้รันระบบเดียวกันบนคอมพิวเตอร์เครื่องเดียว เหมาะสำหรับการสาธิตหรือทดลองใช้ ไม่ใช่การตั้งค่าสำหรับใช้งานจริง เพราะไม่มีการสำรองข้อมูล ไม่มี HTTPS และไม่มีเซิร์ฟเวอร์อีเมล

1. ทำตาม[ขั้นตอนติดตั้ง](#ติดตั้ง)เพื่อสร้าง `.env` ให้คง `PUBLIC_URL=http://localhost` และเว้น `DOMAIN=` กับ `SMTP_HOST=` ไว้
2. เริ่มระบบจากโฟลเดอร์รากของโครงการ

   ```sh
   docker compose --env-file .env -f deploy/compose.prod.yml up -d --wait
   ```

3. เปิด `http://localhost` การสมัครสมาชิกเปิดอยู่ ให้สมัครแล้วสร้างเวิร์กสเปซ คุณจะเป็นเจ้าของ
4. เมื่อไม่มี `SMTP_HOST` เซิร์ฟเวอร์จะเขียนอีเมลทุกฉบับลงบันทึก ลิงก์ยืนยันจึงอยู่ตรงนั้น

   ```sh
   docker compose --env-file .env -f deploy/compose.prod.yml logs server | grep verify-email
   ```

   เปิดลิงก์เพื่อยืนยันบัญชี

5. หยุดระบบด้วยคำสั่ง `down` ตาม[การดูแลระบบ](/th/operate#commands) ข้อมูลยังคงอยู่ จึงการเริ่มครั้งถัดไปจะมีบัญชีเดิม

ถ้าพอร์ต 80 ถูกใช้อยู่บนเครื่องของคุณ ให้ทำตาม[ขั้นตอนเรื่องพอร์ต](#ports)

## หลังเริ่มครั้งแรก

- ตรวจสถานะด้วย `ps` และอ่านหน้า[การดูแลระบบ](/th/operate) สำหรับบันทึก การสำรองข้อมูล และการอัปเกรด
- อ่าน[การตั้งค่า](/th/configuration) เพื่อเลือกโมดูลเสริมที่จะเปิดด้วย `MODULES_ENABLED` ไฟล์ `.env.example` เปิดทั้งสี่ตัวไว้ ถ้าไม่ตั้งตัวแปรนี้ จะมีเฉพาะ `notify` ที่ทำงาน
- ข้อจำกัดที่ทราบในเวอร์ชัน 0.1.0: ชื่อบักเก็ต MinIO คือ `samnak` และต้องคงไว้เช่นนั้น ไฟล์ Compose สร้างอิมเมจจากโค้ดที่คุณมี ยังไม่ดึงอิมเมจรุ่นจริงจากทะเบียนของ GitHub Container Registry
