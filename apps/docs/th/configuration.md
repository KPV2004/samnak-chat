# การตั้งค่า

Samnak Chat อ่านการตั้งค่าจากตัวแปรสภาพแวดล้อม ชุดติดตั้งสำหรับใช้งานจริงอ่านค่าจากไฟล์ `.env` ที่คัดลอกมาจาก `.env.example` ตัวแปรแต่ละตัวด้านล่างแสดงค่าใน `.env.example` และค่าเริ่มต้นที่เซิร์ฟเวอร์ใช้เมื่อค่าว่างหรือไม่ได้ตั้ง

ค่าใน `.env` ถูกอ่านโดยไฟล์ Compose แล้วส่งต่อให้คอนเทนเนอร์ การตั้งค่าบางอย่างเซิร์ฟเวอร์ใช้โดยตรง บางอย่างใช้โดยชุดบริการรอบข้าง ดูจากคอลัมน์ **ใช้โดย**

## จำเป็นต้องตั้ง

| ตัวแปร | ใช้โดย | ตัวอย่างใน `.env.example` | ความหมาย |
| --- | --- | --- | --- |
| `JWT_SECRET` | server | `change-me` | ใช้ลงนาม access token เซิร์ฟเวอร์จะหยุดทำงานตอนเริ่มถ้าค่านี้ว่าง ใช้สตริงสุ่มยาว ๆ |
| `DATABASE_URL` | server | `postgres://samnak:samnak@localhost:5432/samnak?sslmode=disable` | การเชื่อมต่อ PostgreSQL ไฟล์ Compose สร้าง URL ของตัวเองจาก `POSTGRES_PASSWORD` คุณจึงไม่ต้องตั้งค่านี้ที่นั่น |
| `REDIS_URL` | server | `redis://localhost:6379/0` | การเชื่อมต่อ Redis เซิร์ฟเวอร์เชื่อมต่อตอนเริ่ม และจะหยุดทำงานถ้า Redis ไม่ตอบ |

## ที่เก็บไฟล์

| ตัวแปร | ใช้โดย | ตัวอย่าง | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- | --- |
| `S3_ENDPOINT` | server | `http://localhost:9000` | ไม่มี | ที่อยู่ของ MinIO หรือบริการ S3 อื่น ตามที่เซิร์ฟเวอร์เข้าถึง ไฟล์ Compose ตั้งค่านี้เป็นบริการ `minio` |
| `S3_PUBLIC_ENDPOINT` | server | ไม่ได้ตั้ง | เท่ากับ `S3_ENDPOINT` | ที่อยู่ที่เบราว์เซอร์ใช้อัปโหลดและดาวน์โหลดไฟล์ ไฟล์ Compose ตั้งค่านี้เป็น `PUBLIC_URL` |
| `S3_BUCKET` | server, ชุดบริการ | `samnak` | ไม่มี | บักเก็ตสำหรับไฟล์แนบ ให้คงเป็น `samnak` เพราะเส้นทางของ Caddy และการตั้งค่า MinIO ใช้ชื่อนี้ |
| `S3_ACCESS_KEY`, `S3_SECRET_KEY` | server | `minioadmin` | ไม่มี | คีย์สำหรับเข้าบักเก็ต ใช้ค่าสุ่มเมื่อใช้งานจริง |
| `MINIO_ROOT_USER`, `MINIO_ROOT_PASSWORD` | ชุดบริการ | `minioadmin` | ไม่มี | บัญชีเข้าสู่ระบบ MinIO ต้องตรงกับ `S3_ACCESS_KEY` และ `S3_SECRET_KEY` |

ลิงก์อัปโหลดและดาวน์โหลดแบบลงนามล่วงหน้ามีอายุ 15 นาที

## ที่อยู่

| ตัวแปร | ใช้โดย | ตัวอย่าง | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- | --- |
| `PUBLIC_URL` | ชุดบริการ | `http://localhost` | `http://localhost` | ที่อยู่ที่ผู้ใช้เปิด พร้อมพอร์ตถ้าไม่ใช่ 80 หรือ 443 ลิงก์ในอีเมลและลิงก์ไฟล์ใช้ค่านี้ |
| `WEB_URL` | server | `http://localhost:5173` | `http://localhost:5173` | ฐานของลิงก์ในอีเมล ไฟล์ Compose ตั้งเป็น `PUBLIC_URL` |
| `DOMAIN` | ชุดบริการ | ว่าง | ว่าง (HTTP ธรรมดาที่พอร์ต 80) | ชื่อโฮสต์สำหรับ HTTPS อัตโนมัติ เช่น `chat.example.com` ตั้งค่านี้เฉพาะเมื่อพอร์ต 80 และ 443 เข้าถึงเครื่องนี้ได้ |
| `HTTP_ADDR` | server | `:8080` | `:8080` | ที่อยู่ที่ API รับการเชื่อมต่อ ภายในคอนเทนเนอร์ |
| `HTTP_PORT`, `HTTPS_PORT` | ชุดบริการ | ไม่มีใน `.env.example` | `80`, `443` | พอร์ตบนเครื่องโฮสต์ที่ Caddy เปิด ตั้งในเชลล์ ไม่ใช่ใน `.env` และตั้ง `PUBLIC_URL` ให้ตรงกัน |
| `STACK_SUBNET` | ชุดบริการ | `172.28.0.0/24` | `172.28.0.0/24` | ช่วงที่อยู่ของเครือข่ายส่วนตัวของระบบ เปลี่ยนเฉพาะเมื่อชนกับเครือข่าย Docker อื่น |
| `TRUSTED_PROXIES` | server | ว่าง | ว่าง (ไม่เชื่อถือพร็อกซีใด) | ที่อยู่หรือช่วง CIDR ของพร็อกซีแบบย้อนกลับ คั่นด้วยจุลภาค เซิร์ฟเวอร์เชื่อหัว `X-Forwarded-For` จากพร็อกซีเหล่านี้เมื่อนับคำขอตาม IP ของไคลเอนต์ ไฟล์ Compose ตั้งเป็น `STACK_SUBNET` ซึ่งมีเพียง Caddy ที่เข้าถึงเซิร์ฟเวอร์ได้ |

## อีเมล

เมื่อ `SMTP_HOST` ว่าง เซิร์ฟเวอร์จะเขียนอีเมลแต่ละฉบับลงบันทึกและไม่ส่งจริง เหมาะกับการทดลองใช้ สำหรับใช้งานจริงให้ตั้งเซิร์ฟเวอร์อีเมลจริง

| ตัวแปร | ตัวอย่าง | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `SMTP_HOST` | ว่าง | ว่าง | เซิร์ฟเวอร์อีเมล ถ้าว่างหมายถึงเขียนลงบันทึก |
| `SMTP_PORT` | `1025` | `587` | พอร์ต พอร์ต 465 ใช้ TLS ตั้งแต่ต้น พอร์ตอื่นใช้ STARTTLS เมื่อเซิร์ฟเวอร์เสนอให้ใช้ |
| `SMTP_USERNAME`, `SMTP_PASSWORD` | ว่าง | ว่าง | บัญชีสำหรับเข้าเซิร์ฟเวอร์อีเมล ถ้าเซิร์ฟเวอร์ต้องการ |
| `SMTP_FROM` | `Samnak <no-reply@localhost>` | `Samnak <no-reply@localhost>` | ที่อยู่ผู้ส่ง |

อีเมลที่ระบบส่งมีไว้สำหรับการยืนยันอีเมลตอนสมัครสมาชิก การส่งการยืนยันอีกครั้ง และการตั้งรหัสผ่านใหม่ อีเมลจากโมดูลการแจ้งเตือนเป็นแผนงาน

## โมดูล {#modules}

| ตัวแปร | ตัวอย่าง | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `MODULES_ENABLED` | `notify,task,approval,helpdesk` | ไม่ได้ตั้ง: เปิด `notify` เท่านั้น | โมดูลเสริมที่จะเปิด โมดูลหลัก `auth`, `workspace` และ `chat` เปิดอยู่เสมอ |

การตั้งค่าสามแบบทำงานต่างกันดังนี้

| การตั้งค่า | โมดูลที่เปิด |
| --- | --- |
| ไม่ได้ตั้ง | `auth`, `workspace`, `chat`, `notify` |
| ว่าง (`MODULES_ENABLED=`) | `auth`, `workspace`, `chat` เท่านั้น |
| `task,helpdesk` | โมดูลหลัก กับ `task` และ `helpdesk` |

ชื่อโมดูลไม่สนตัวพิมพ์ใหญ่เล็ก ถ้าใส่ชื่อที่ไม่รู้จัก เซิร์ฟเวอร์จะหยุดทำงานตอนเริ่มพร้อมข้อความแจ้ง โมดูลที่ปิดอยู่จะตอบ 404 ที่เส้นทางของมัน และเมนูของมันถูกซ่อน ข้อมูลของมันยังคงอยู่ในฐานข้อมูล หลังเปลี่ยนค่านี้ให้เริ่มเซิร์ฟเวอร์ใหม่

`GET /api/v1/meta` จะคืนรายการโมดูลที่เปิดอยู่

## ขีดจำกัดการเรียก {#rate-limits}

API ทุกคำขอถูกจำกัดจำนวนต่อนาที การเข้าสู่ระบบมีขีดจำกัดของตัวเองที่เข้มกว่า

| ตัวแปร | ตัวอย่าง | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `RATE_LIMIT_ENABLED` | `true` | `true` | เปิดหรือปิดขีดจำกัดสำหรับ API ทั้งหมด |
| `RATE_LIMIT_PER_MINUTE` | `600` | `600` | จำนวนคำขอต่อนาทีที่ผู้ใช้ที่เข้าสู่ระบบแล้วเรียกได้ |
| `RATE_LIMIT_IP_PER_MINUTE` | `120` | `120` | จำนวนคำขอต่อนาทีที่ไคลเอนต์ที่ยังไม่เข้าสู่ระบบเรียกได้ นับตาม IP |

เมื่อเกินขีดจำกัด API ตอบ 429 พร้อมหัว `Retry-After` การตรวจสุขภาพระบบ `/metrics` และการเชื่อมต่อ WebSocket ไม่ถูกนับ การเข้าสู่ระบบอนุญาตให้ล้มเหลวได้ 5 ครั้งต่อนาทีสำหรับแต่ละอีเมลและแต่ละ IP

## รหัสผ่านของชุดบริการ Compose

| ตัวแปร | ตัวอย่าง | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `POSTGRES_PASSWORD` | `samnak` | `samnak` | รหัสผ่านฐานข้อมูล ตั้งก่อนเริ่มครั้งแรก เพราะฐานข้อมูลจะเก็บรหัสผ่านที่ถูกสร้างไว้ตอนนั้น |

ก่อนใช้งานจริง เปลี่ยนค่าตัวอย่างทุกค่า (`change-me`, `minioadmin`, `samnak`)
