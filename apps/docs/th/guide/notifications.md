# การแจ้งเตือน

การแจ้งเตือนบอกคุณเมื่อมีเรื่องที่ต้องการคุณ เช่น มีคนกล่าวถึงคุณ มีข้อความส่วนตัว มีงานมอบหมายให้คุณ หรือมีคำขอรอการตัดสินใจ การแจ้งเตือนจะรวมอยู่ที่กระดิ่งด้านบนของแอป หน้านี้ต้องใช้โมดูล `notify` ซึ่งเปิดอยู่โดยค่าเริ่มต้น

## กระดิ่ง

กระดิ่งแสดงจำนวนการแจ้งเตือนที่คุณยังไม่ได้อ่าน เปิดกระดิ่งเพื่อดูรายการ เลือกการแจ้งเตือนเพื่อไปยังเรื่องนั้น หรือเลือก **ทำเครื่องหมายว่าอ่านทั้งหมด**

การแจ้งเตือนมาถึงแบบเรียลไทม์ขณะที่แอปเปิดอยู่ เมื่อคุณออฟไลน์ การแจ้งเตือนจะรออยู่ในรายการ

## สิ่งที่แจ้งให้คุณทราบ

| ส่วน | การแจ้งเตือน |
| --- | --- |
| แชท | มีคนกล่าวถึงคุณ ข้อความส่วนตัว และการตอบในเธรดที่คุณติดตามอยู่ |
| งาน | งานที่มอบหมายให้คุณ งานใกล้ครบกำหนด และงานเลยกำหนด |
| ศูนย์ช่วยเหลือ | คำขอใหม่ คำขอที่มอบหมายให้คุณ การเปลี่ยนสถานะ และความคิดเห็นในคำขอ |
| คำขออนุมัติ | คำขอที่ส่งมาถึงคุณเพื่อตัดสิน และคำขอที่คุณส่งไปที่ได้รับการอนุมัติ ไม่อนุมัติ หรือยกเลิก |

## การตั้งค่า

เปิด **ตั้งค่าการแจ้งเตือน** จากเมนูบัญชี การตั้งค่ามีสามส่วน

**ประเภทการแจ้งเตือน** แต่ละประเภทมีสวิตช์ ประเภทที่ปิดอยู่จะไม่ถูกส่งถึงคุณ ใช้วิธีนี้เพื่อปิดการแจ้งเตือนที่คุณไม่ต้องการ เช่น การเตือนงานที่เลยกำหนด

**ช่องที่ปิดเสียง** การแจ้งเตือนจากช่องที่ปิดเสียงจะไม่ถูกส่งถึงคุณ แม้จะมีคนกล่าวถึงคุณในช่องนั้น ปิดเสียงช่องได้โดยเปิด **ตัวเลือกของช่อง** ใน Messenger แล้วเลือก **ปิดเสียงช่องนี้** เลิกปิดเสียงได้ที่เดิม หรือจากรายการภายใต้ **ช่องที่ปิดเสียง** ในการตั้งค่า

**ห้ามรบกวน** เลือก **จาก** และ **ถึง** ต้องตั้งทั้งสองค่า หรือเคลียร์ทั้งสองค่า เวลาเริ่มและเวลาสิ้นสุดต้องไม่เป็นเวลาเดียวกัน ระหว่างช่วงเวลานี้จะไม่มีป๊อปอัปปรากฏขึ้น การแจ้งเตือนยังถูกเก็บไว้และนับในกระดิ่ง ช่วงเวลาใช้เขตเวลาในโปรไฟล์ของคุณ

## การเก็บการแจ้งเตือน

การแจ้งเตือนที่อ่านแล้วซึ่งเก่ากว่าประมาณ 90 วันจะถูกลบโดยอัตโนมัติ การแจ้งเตือนที่ยังไม่ได้อ่านจะเก็บไว้จนกว่าคุณจะอ่าน

## ยังไม่มีในเวอร์ชัน 0.1.0

การแจ้งเตือนแบบพุชและการแจ้งเตือนทางอีเมลเป็นแผนงาน ในเวอร์ชัน 0.1.0 การแจ้งเตือนจะมาถึงคุณเฉพาะในแอป อีเมลที่ระบบส่งสำหรับการสมัครสมาชิกและรหัสผ่านจะส่งไปยังที่อยู่อีเมลของคุณ ดู[บัญชี](/th/guide/account)
