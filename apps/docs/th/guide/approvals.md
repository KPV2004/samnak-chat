# คำขออนุมัติ

คำขออนุมัติให้คนหนึ่งคนตัดสินใจเรื่องหนึ่ง เช่น วันลา การจัดซื้อ หรือคำขอทั่วไปอื่น ผู้ขอกรอกแบบฟอร์ม ผู้อนุมัติกดอนุมัติหรือไม่อนุมัติ และทั้งสองฝ่ายเห็นผลบนการ์ดในแชท หน้านี้ต้องใช้โมดูล `approval` ซึ่งปิดอยู่จนกว่า `MODULES_ENABLED` จะระบุไว้ ดู[การตั้งค่า](/th/configuration#modules)

## ส่งคำขอ

เปิด **คำขออนุมัติ** แล้วเลือก **สร้างคำขอ** จากนั้นเลือกประเภท

**ใบลา**

| ช่อง | กฎ |
| --- | --- |
| ประเภทการลา | ลาพักร้อน ลาป่วย ลากิจ หรืออื่น ๆ |
| วันเริ่มและวันสิ้นสุด | วันสิ้นสุดต้องไม่ก่อนวันเริ่ม |
| ลาครึ่งวัน | เต็มวัน ครึ่งเช้า หรือครึ่งบ่าย ลาครึ่งวันใช้ได้เฉพาะวันเดียว |
| เหตุผล | จำเป็นต้องกรอก ไม่เกิน 1,000 ตัวอักษร |

**คำขอทั่วไป**

| ช่อง | กฎ |
| --- | --- |
| หัวข้อ | จำเป็นต้องกรอก ไม่เกิน 200 ตัวอักษร และต้องอยู่บรรทัดเดียว |
| รายละเอียด | ไม่บังคับ ไม่เกิน 4,000 ตัวอักษร |
| จำนวนเงิน | ไม่บังคับ เป็นตัวเลข เช่น `1200.50` มีทศนิยมได้ไม่เกินสองตำแหน่ง |
| สกุลเงิน | รหัสสามตัวอักษร ค่าเริ่มต้นคือ `THB` เมื่อคุณกรอกจำนวนเงิน |

ทั้งสองประเภทแนบไฟล์ได้ คำขอหนึ่งรายการแนบได้สูงสุด 10 ไฟล์ และแต่ละไฟล์ใหญ่ได้ถึง 50 MB

### ใครเป็นผู้ตัดสิน

คำขอจะส่งไปยังผู้อนุมัติที่คุณระบุ ซึ่งต้องเป็นสมาชิกที่ใช้งานอยู่ของเวิร์กสเปซ และไม่ใช่ตัวคุณเอง ถ้าคุณไม่ระบุใคร คำขอจะส่งไปยังหัวหน้ากลุ่มของคุณ ฟอร์มแสดงค่าเริ่มต้นนี้ว่า **อัตโนมัติ: หัวหน้ากลุ่มของฉัน** ถ้าคุณไม่อยู่ในกลุ่มที่มีหัวหน้า คุณต้องระบุผู้อนุมัติเอง

กลุ่มและหัวหน้ากลุ่มตั้งค่าโดยเจ้าของและผู้ดูแล ดู[กลุ่ม](#groups) ด้านล่าง

## ตัดสินคำขอ

คำขอปรากฏเป็นการ์ดในข้อความส่วนตัวระหว่างคุณกับผู้ขอ และอยู่ในรายการ **รอฉันอนุมัติ** การ์ดมีปุ่ม **อนุมัติ** และ **ไม่อนุมัติ** รวมทั้งลิงก์ **เปิดคำขอ**

- **อนุมัติ** คำขอเปลี่ยนเป็น **อนุมัติแล้ว** และผู้ขอได้รับการแจ้งเตือน
- **ไม่อนุมัติ** คุณต้องระบุเหตุผล ผู้ขอจะเห็นเหตุผลนี้ และเหตุผลจะอยู่ในประวัติของคำขอ คำขอเปลี่ยนเป็น **ไม่อนุมัติ**

การตัดสินใจเป็นที่สุด เมื่อคำขอถูกอนุมัติ ไม่อนุมัติ หรือยกเลิกแล้ว จะไม่มีใครเปลี่ยนสถานะได้อีก

มีเพียงผู้อนุมัติเท่านั้นที่อนุมัติหรือไม่อนุมัติได้ และทำได้เฉพาะตอนที่คำขอยังรออยู่

## ยกเลิกคำขอ

ผู้ขอกด **ยกเลิกคำขอ** ได้ตอนที่คำขอยังรออยู่ คำขอที่ยกเลิกแล้วก็เป็นที่สุดเช่นกัน

## รายการและสถานะ

- **รอฉันอนุมัติ** แสดงคำขอที่คุณต้องตัดสิน แถบด้านข้างแสดงจำนวนคำขอ
- **คำขอของฉัน** แสดงคำขอที่คุณส่งไป

แต่ละคำขอมีสถานะ ได้แก่ **รออนุมัติ** **อนุมัติแล้ว** **ไม่อนุมัติ** หรือ **ยกเลิกแล้ว** กรองรายการตามสถานะได้

มีเพียงผู้ขอและผู้อนุมัติเท่านั้นที่มองเห็นคำขอ คนอื่นจะได้รับคำตอบว่าไม่พบ

## ประวัติ

แต่ละคำขอมีประวัติว่าใครส่ง ใครอนุมัติ ไม่อนุมัติ หรือยกเลิก เมื่อไร และเหตุผลของการไม่อนุมัติ ดาวน์โหลดไฟล์แนบได้จากหน้าคำขอ

## การแจ้งเตือน

- ผู้อนุมัติได้รับการแจ้งเตือนเมื่อมีคำขอส่งถึง ในประเภท **คำขออนุมัติ**
- ผู้ขอได้รับการแจ้งเตือนเมื่อคำขออนุมัติ ไม่อนุมัติ หรือยกเลิก ในประเภท **คำขอที่อนุมัติแล้ว** **คำขอที่ไม่อนุมัติ** หรือ **คำขอที่ยกเลิก**

คุณปิดแต่ละประเภทได้ใน[การตั้งค่าการแจ้งเตือน](/th/guide/notifications)

## กลุ่ม {#groups}

**กลุ่ม** อยู่ในส่วนเวิร์กสเปซเมื่อเปิดโมดูลการอนุมัติ กลุ่มคือทีมที่มีหัวหน้า ซึ่งอนุมัติคำขอของสมาชิกโดยค่าเริ่มต้น เจ้าของและผู้ดูแลสร้างกลุ่ม เปลี่ยนชื่อ หรือลบกลุ่ม กำหนดสมาชิก และเลือกหัวหน้าได้ สมาชิกของกลุ่มไม่ต้องทำอะไรเพิ่ม ผู้อนุมัติเริ่มต้นจะตามกลุ่มเอง

การลบกลุ่มไม่ได้เอาสมาชิกออกจากเวิร์กสเปซ ลบเฉพาะกลุ่มเท่านั้น
