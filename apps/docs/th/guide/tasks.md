# งาน

งานทำให้ข้อความกลายเป็นงานที่มีคนรับผิดชอบ งานหนึ่งมีชื่อ ผู้รับผิดชอบ วันครบกำหนด (ถ้ามี) ความสำคัญ และสถานะ หน้านี้ต้องใช้โมดูล `task` ซึ่งปิดอยู่จนกว่า `MODULES_ENABLED` จะระบุไว้ ดู[การตั้งค่า](/th/configuration#modules)

## สร้างงาน

มีสามวิธี

- **จากข้อความ** เปิดเมนูการกระทำของข้อความ แล้วเลือก **สร้างงาน** หัวข้อจะมาจากฟอร์ม และคุณเลือกผู้รับผิดชอบ วันครบกำหนด และความสำคัญได้
- **ด้วยคำสั่ง** ในช่องใดก็ได้ พิมพ์ `/task` แล้วตามด้วยชื่องาน ถ้าต้องการมอบหมาย ให้พิมพ์ `@` หลังชื่องาน แล้วเลือกคนจากรายการ เช่น `/task จัดใบเสนอราคาสามใบสำหรับโน้ตบุ๊ก 12 เครื่อง` แล้วตามด้วย `@มะลิ`
- **จากคำขอความช่วยเหลือ** เปิดคำขอ แล้วเลือก **สร้างงาน** ดู[ศูนย์ช่วยเหลือ](/th/guide/helpdesk)

งานจะแสดงเป็นการ์ดในช่องที่ถูกสร้าง การ์ดแสดงชื่องาน ผู้รับผิดชอบ ความสำคัญ วันครบกำหนด และสถานะ

## ข้อมูลของงาน

| ข้อมูล | กฎ |
| --- | --- |
| ชื่องาน | 1 ถึง 200 ตัวอักษร |
| ผู้รับผิดชอบ | ไม่บังคับ งานที่ยังไม่มีผู้รับผิดชอบจะไม่อยู่ใน **งานของฉัน** ของใคร |
| วันครบกำหนด | ไม่บังคับ |
| ความสำคัญ | ต่ำ ปกติ หรือสูง |
| สถานะ | ยังไม่ทำ กำลังทำ หรือเสร็จแล้ว |

## แก้ไขงาน

เปลี่ยนสถานะด้วยตัวเลือกบนการ์ดงาน เฉพาะผู้สร้างงาน ผู้รับผิดชอบ เจ้าของ หรือผู้ดูแลเท่านั้นที่แก้ไขงานหรือเปลี่ยนสถานะได้

เมื่อมอบหมายงานให้ใคร ผู้นั้นจะได้รับการแจ้งเตือนในประเภท **งานที่มอบหมายให้คุณ** ดู[การแจ้งเตือน](/th/guide/notifications)

## งานของฉัน

**งานของฉัน** แสดงงานที่มอบหมายให้คุณ ครอบคลุมทุกช่อง หน้านี้มีตัวกรองเดียวกับลิงก์ในแถบด้านข้าง

- **งานของฉัน** แสดงงานที่ยังไม่เสร็จ คือ ยังไม่ทำ และกำลังทำ นี่คือมุมมองเริ่มต้น
- **ครบกำหนดวันนี้** แสดงงานที่ครบกำหนดวันนี้
- **เลยกำหนดแล้ว** แสดงงานที่ยังไม่เสร็จและเลยวันครบกำหนดแล้ว
- **เสร็จแล้ว** แสดงงานที่เสร็จ
- **ตามช่อง** แสดงรายการช่องที่มีงานที่ยังไม่เสร็จของคุณ พร้อมจำนวนของแต่ละช่อง

แถบเครื่องมือกรองตามสถานะ วันครบกำหนด (เลยกำหนดแล้ว ครบกำหนดวันนี้ หรือครบกำหนดภายใน 7 วัน) และช่อง ใช้ **ล้างตัวกรอง** เพื่อกลับไปค่าเริ่มต้น

## การเตือนความจำ

ระบบตรวจงานที่ครบกำหนดทุก 5 นาที สำหรับแต่ละงานที่ยังไม่เสร็จ มีผู้รับผิดชอบ และมีวันครบกำหนด ระบบจะส่งการแจ้งเตือนถึงผู้รับผิดชอบ โดยส่งหนึ่งครั้งต่อวันครบกำหนดหนึ่งวัน

- เมื่องานจะครบกำหนดภายใน 24 ชั่วโมง ในประเภท **งานใกล้ครบกำหนด**
- เมื่องานเลยกำหนดแล้ว ในประเภท **งานเลยกำหนด**

คุณปิดประเภทใดประเภทหนึ่งได้ใน[การตั้งค่าการแจ้งเตือน](/th/guide/notifications) การเตือนความจำมาทางกระดิ่งการแจ้งเตือนและแบบเรียลไทม์ขณะที่แอปเปิดอยู่ การเตือนความจำทางการพุชและทางอีเมลเป็นแผนงาน ยังไม่มีในเวอร์ชัน 0.1.0
