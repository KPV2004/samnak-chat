# เวิร์กสเปซ

เวิร์กสเปซคือพื้นที่ของหนึ่งองค์กรใน Samnak Chat มีช่อง สมาชิก คำเชิญ และกลุ่มของตัวเอง คุณเป็นสมาชิกของหลายเวิร์กสเปซได้ และสลับระหว่างกันด้วยไอคอนทางซ้ายของแอป

## สร้างเวิร์กสเปซ

เลือกไทล์รูปเส้นประในแถบเวิร์กสเปซ แล้วกรอก

- **ชื่อเวิร์กสเปซ**
- **ชื่อย่อ** (slug) 3 ถึง 40 ตัวอักษร ใช้ตัวอักษรภาษาอังกฤษพิมพ์เล็ก ตัวเลข และขีดกลาง ต้องไม่ซ้ำกับของเวิร์กสเปซอื่น

คุณจะเป็น **เจ้าของ** ของเวิร์กสเปซนั้น

## บทบาท

| บทบาท | ทำอะไรได้ |
| --- | --- |
| **เจ้าของ** | ทำได้ทุกอย่างที่ผู้ดูแลทำได้ และยังให้บทบาทเจ้าของและเปลี่ยนเจ้าของได้ เจ้าของที่ใช้งานอยู่คนสุดท้ายจะลดบทบาทหรือปิดใช้งานไม่ได้ |
| **ผู้ดูแล** | จัดการสมาชิก คำเชิญ และกลุ่ม และอ่านบันทึกการดำเนินการได้ |
| **หัวหน้า** | มีสิทธิ์เหมือนสมาชิกในเวอร์ชัน 0.1.0 การเป็นหัวหน้าของกลุ่มเป็นการตั้งค่าอีกอย่างหนึ่ง และเป็นสิ่งที่ทำให้บุคคลนั้นเป็นผู้อนุมัติเริ่มต้น |
| **สมาชิก** | ใช้ช่องได้ สร้างช่องได้ และส่งคำขอได้ |
| **ผู้เยี่ยมชม** | เห็นและใช้ได้เฉพาะช่องที่มีคนเพิ่มเข้าไป สร้างช่องไม่ได้ |

เจ้าหน้าที่ศูนย์ช่วยเหลือไม่ใช่บทบาทของเวิร์กสเปซ เจ้าหน้าที่คือสมาชิกที่ถูกตั้งให้ดูแลคิวของศูนย์ช่วยเหลือหนึ่งคิวหรือมากกว่า ดู[ศูนย์ช่วยเหลือ](/th/guide/helpdesk)

เจ้าของและผู้ดูแลจัดการสมาชิกและคำเชิญ และเฉพาะเจ้าของเท่านั้นที่ให้บทบาทเจ้าของได้

## สมาชิก

เปิด **สมาชิก** เพื่อดูทุกคนในเวิร์กสเปซ พร้อมบทบาท สถานะ และวันที่เข้าร่วม เจ้าของและผู้ดูแลทำได้ดังนี้

- **เปลี่ยนบทบาท**
- **ปิดใช้งาน** สมาชิก ซึ่งหยุดการเข้าถึงโดยไม่ลบออก และ **เปิดใช้งาน** อีกครั้งภายหลังได้
- **ลบ** สมาชิก สมาชิกจะหมดสิทธิ์เข้าถึงช่องของเวิร์กสเปซ และคุณเชิญเขากลับมาได้ภายหลัง

ทุกการเปลี่ยนแปลงถูกบันทึกในบันทึกการดำเนินการ

## คำเชิญ

เปิด **คำเชิญ** เฉพาะเจ้าของและผู้ดูแลที่สร้างและจัดการคำเชิญได้

1. เลือกบทบาทที่บุคคลนั้นจะได้ ได้แก่ ผู้ดูแล สมาชิก หรือผู้เยี่ยมชม คำเชิญให้บทบาทเจ้าของไม่ได้ ส่วนหัวหน้าจะตั้งหลังจากบุคคลนั้นเข้าร่วมแล้ว
2. ใส่อีเมลหรือไม่ก็ได้
   - **ถ้ามีอีเมล** มีเพียงที่อยู่นั้นเท่านั้นที่รับคำเชิญได้
   - **ถ้าไม่มีอีเมล** ใครที่มีลิงก์ก็รับคำเชิญได้
3. สร้างคำเชิญแล้วคัดลอกลิงก์ ลิงก์จะแสดง**เพียงครั้งเดียว** ดังนั้นคัดลอกก่อนออกจากหน้า

คำเชิญมีอายุ 7 วัน เพิกถอนคำเชิญที่ยังค้างอยู่ได้จากหน้าเดียวกัน รายการคำเชิญจะไม่แสดงลิงก์อีกหลังจากนั้น

ในการรับคำเชิญ ให้เปิดลิงก์ แล้วเข้าสู่ระบบ หรือสมัครสมาชิกก่อน หน้านั้นจะแสดงเวิร์กสเปซที่คุณกำลังจะเข้าร่วม คำเชิญจะใช้ไม่ได้เมื่อถูกส่งไปยังอีเมลอื่น เมื่อหมดอายุหรือถูกเพิกถอน หรือเมื่อคุณเป็นสมาชิกอยู่แล้ว

## กลุ่ม

**กลุ่ม** ปรากฏเมื่อเปิดโมดูลการอนุมัติ กลุ่มคือทีมที่มีหัวหน้า ซึ่งอนุมัติคำขอของสมาชิกโดยค่าเริ่มต้น เจ้าของและผู้ดูแลสร้างกลุ่ม ตั้งชื่อ กำหนดสมาชิก และเลือกหัวหน้าได้ การลบกลุ่มจะเก็บสมาชิกไว้ในเวิร์กสเปซ ดู[คำขออนุมัติ](/th/guide/approvals#groups)

## บันทึกการดำเนินการ

เจ้าของและผู้ดูแลเปิด **บันทึกการดำเนินการ** ได้ บันทึกนี้แสดงการเปลี่ยนแปลงในเวิร์กสเปซ เรียงจากใหม่ไปเก่า พร้อมบอกว่าใครเป็นผู้ทำ เมื่อไร และเปลี่ยนอะไร

- คำเชิญที่สร้างและที่เพิกถอน
- บทบาทและสถานะของสมาชิกที่เปลี่ยน และสมาชิกที่ถูกลบ
- กลุ่มที่สร้าง แก้ไข และลบ และสมาชิกของกลุ่มที่เปลี่ยน

สมาชิกที่ออกไปแล้วยังปรากฏในบันทึก แสดงเป็น **สมาชิกเดิม**
