โมดูลงาน คำขออนุมัติ และศูนย์ช่วยเหลือ

  1. งานที่มอบหมายจากข้อความ

    สร้างงานจากเมนูของข้อความหรือพิมพ์ /task การ์ดแสดงผู้รับผิดชอบ ความสำคัญ และวันกำหนดส่ง

  2. คำขออนุมัติที่ตัดสินบนการ์ด

    ใบลาหรือคำขอทั่วไปไปถึงผู้อนุมัติเป็นการ์ดในข้อความส่วนตัว ถ้าไม่อนุมัติต้องระบุเหตุผล

  3. เรื่องแจ้งปัญหาแยกตามคิว

    แอดมินสร้างคิว เช่น IT HR หรืออาคาร แต่ละเรื่องมีเลขประจำคิว และเจ้าหน้าที่ของคิวกดรับเรื่องได้

ติดตั้งเองด้วย Docker Compose

ไฟล์ Compose ไฟล์เดียวเริ่มได้ทุกส่วน ทั้งเว็บแอปหลัง Caddy, API server, PostgreSQL, Redis และ MinIO สำหรับเก็บไฟล์

$ git clone https://github.com/KPV2004/samnak-chat.git$ cd samnak-chat && cp .env.example .env# ตั้งค่า JWT_SECRET รหัสผ่าน และ PUBLIC_URL$ docker compose --env-file .env \    -f deploy/compose.prod.yml up -d --wait
  • ต้องมีDocker พร้อม Compose v2 หน่วยความจำว่างราว 2 GB และพื้นที่ดิสก์ 5 GB
  • HTTPSตั้งค่า DOMAIN แล้ว Caddy จะขอใบรับรองให้
  • Imageamd64 และ arm64 ที่ ghcr.io/kpv2004/samnak-chat/server และ /web ส่วน Compose สร้างจากโค้ดที่ clone มา

คำถามก่อนติดตั้ง

การใช้งานโดยไม่เปิดงานหรือศูนย์ช่วยเหลือ

ได้ งาน คำขออนุมัติ และศูนย์ช่วยเหลือเป็นโมดูลที่เปิดใน MODULES_ENABLED ส่วนแชท บัญชีผู้ใช้ workspace และการแจ้งเตือนเปิดอยู่เสมอ

ค่าใช้จ่ายและไลเซนส์

ซอฟต์แวร์ใช้ฟรีภายใต้ AGPL-3.0 คุณจ่ายเฉพาะค่าเซิร์ฟเวอร์ที่รันระบบ

แอปมือถือและเดสก์ท็อป

ยังไม่มี เว็บแอปใช้ได้บนหน้าจอกว้างตั้งแต่ 360 px แอปเดสก์ท็อปและมือถืออยู่ในแผน

ที่เก็บข้อมูล

ในฐานข้อมูล PostgreSQL และที่เก็บไฟล์ MinIO ของระบบที่คุณติดตั้ง บนเครื่องของคุณเอง

อีเมลจาก Samnak Chat

อีเมลยืนยันบัญชีและรีเซ็ตรหัสผ่านใช้เซิร์ฟเวอร์ SMTP ใน .env ถ้าไม่ตั้ง จะเขียนลงบันทึกของเซิร์ฟเวอร์แทน

การอัปเกรดเวอร์ชันใหม่

ดึงโค้ดใหม่แล้วสร้างใหม่ การย้ายฐานข้อมูลจะรันก่อนที่เซิร์ฟเวอร์ตัวใหม่เริ่มทำงาน

โอเพนซอร์ส มีบทบาทผู้ใช้ และสองภาษา

ซอร์สโค้ดอยู่บน GitHub ภายใต้ AGPL-3.0 หน้าจอใช้ได้ทั้งภาษาไทยและอังกฤษ ทุก workspace มีบทบาท Owner, Admin, Manager, Member และ Guest และมี Agent ประจำแต่ละคิวของศูนย์ช่วยเหลือ
