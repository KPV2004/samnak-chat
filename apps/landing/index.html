Modules for tasks, approvals and helpdesk

  1. Tasks assigned from a message

    Make a task from the message menu or with /task. The card shows who has it, its priority and its due date.

  2. Approvals decided on the card

    A leave or general request reaches the approver as a card in a direct message. A rejection needs a reason.

  3. Helpdesk tickets sorted by queue

    Admins set up queues such as IT, HR or Facilities. Each ticket is numbered in its queue, and an agent of the queue claims it.

Self-hosting with Docker Compose

One Compose file starts the web app behind Caddy, the API server, PostgreSQL, Redis and MinIO for files.

$ git clone https://github.com/KPV2004/samnak-chat.git$ cd samnak-chat && cp .env.example .env# set JWT_SECRET, the passwords and PUBLIC_URL$ docker compose --env-file .env \    -f deploy/compose.prod.yml up -d --wait
  • NeedsDocker with Compose v2, about 2 GB of free memory and 5 GB of disk.
  • HTTPSSet DOMAIN and Caddy gets the certificate.
  • Imagesamd64 and arm64 at ghcr.io/kpv2004/samnak-chat/server and /web. Compose builds from your checkout.

Questions before you install

Using it without tasks or helpdesk

Yes. Tasks, approvals and helpdesk are modules you switch on in MODULES_ENABLED. Chat, accounts, workspaces and notifications are always on.

Price and licence

The software is free under AGPL-3.0. You pay for the server it runs on.

Mobile and desktop apps

Not yet. The web app works on screens from 360 px wide. Desktop and mobile apps are planned.

Your data and security

In the PostgreSQL database and the MinIO file store of your own stack, on your machine.

Email from Samnak Chat

Verification and reset mail uses the SMTP server in .env. With none set, it goes to the server log.

Upgrading Samnak Chat

Pull the new code and rebuild. The migrations run before the new server starts.

Open source, with roles and two languages

The source is on GitHub under AGPL-3.0. The interface is in Thai and English, and each workspace has Owner, Admin, Manager, Member and Guest roles, with Agent per helpdesk queue.
